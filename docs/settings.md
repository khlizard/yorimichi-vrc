# 設定と読み込みの仕組み

## 設定ファイル

設定は `%APPDATA%\Yorimichi\yorimichi.settings.json` に保存します (初回起動時に作成)。
「ファイル → 設定…」(トレイのメニューからも可) で開く設定ウィンドウから変更できます。

ファイルを読めないときは、既定の設定で起動してその旨を表示します。元のファイルは `yorimichi.settings.json.bak` に残します。

| キー | 説明 |
| --- | --- |
| `DbPath` | データベースのパス (既定 `yorimichi.db`)。相対パスは設定ファイルのあるフォルダが基準。`%VAR%` を展開します |
| `LogFolders` | `output_log_*.txt` を探すフォルダの一覧 (既定は VRChat のログフォルダ)。同じ名前のファイルは大きいほうを使います |
| `AutoImportIntervalMinutes` | 自動取り込みの間隔 (分、既定 `1`)。`0` で無効 |
| `MinimizeToTray` | `true` なら、閉じるボタンでタスクトレイに残ります (既定 `false`。初めて閉じるときに尋ねます) |
| `PhotoFolders` | 写真を探すフォルダの一覧。初回の既定は、VRChat の設定 (`config.json` の `picture_output_folder`) のフォルダ、無ければ「ピクチャ」の `VRChat` |
| `DayStartHour` | 1 日の区切り (時、既定 `6`)。この時刻までは前日として扱います |
| `Theme` | 表示テーマ。`auto` (Windows に合わせる、既定) / `light` / `dark`。「表示 → テーマ」でも切り替えられます。写真・アルバム・タイムラインは、どのテーマでも暗い配色です |
| `ShowFirstMet` / `ReunionDays` | 初めて会った人と、久しぶり (既定 180 日以上、`0` で無効) に会った人へのバッジ |
| `RawLogRetentionDays` | 生ログを残す日数 (既定 `30`、`0` で無制限)。セッション・プレイヤー・URL・通知は消えません |
| `RawLogNoisePatterns` | 生ログに保存しない行 (前方一致。先頭が `*` なら部分一致) |
| `AutoVacuum` / `AutoVacuumMinDbMb` | データベースの自動最適化と、対象にする最小サイズ (既定 200 MB。空きが 20% 以上のとき実行) |
| `BackupFolder` / `BackupIntervalDays` / `BackupKeepCount` | バックアップの保存先 (既定 `backups`)、間隔 (既定 7 日、`0` で無効)、残す世代数 (既定 3) |
| `UpdateFeed` | 更新の配布元 (URL またはフォルダ)。空欄 (既定) なら GitHub の最新リリース |

自動起動の設定は、設定ファイルではなく Windows のレジストリ (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) に保存します。

## ログの取り込み

- 新しいファイルと、追記されたファイルだけを取り込みます。
- 生ログは全文検索できます。決まった形の雑音の行は保存しません。
- 解析できる項目が増えた版に上げたときは、設定ウィンドウの「全ログを再取り込み」で、残っているログを解析し直せます。

## 写真の読み込み

- 「写真フォルダ」の中を、下の階層まで探します。対象は PNG / JPEG / WebP です。
- 撮影時刻は、次の順で決めます。
  1. VRChat が PNG に書き込んだ情報
  2. ファイル名の日時 (`VRChat_2026-01-10_20-30-00.000_3840x2160.png` など)
  3. ファイルの更新日時
- ワールドと一緒にいた人は、その時刻のログがあるときに表示します。ログが無くても、PNG にワールド名が入っていれば、ワールド名は表示します。
- 同期アプリ (Dropbox、OneDrive など) のオンライン専用ファイルは、中身を読みません。ファイル名の日時だけで一覧に載せます。サムネイルは Windows のサムネイル機能から取得します。
- サムネイルは `%LOCALAPPDATA%\io.github.khlizard.yorimichi\thumbs` に保存します。

## データベースの手入れ

- PC を使っていないとき (入力が 10 分以上なく、CPU の使用率が低く、VRChat が起動していない) と終了時に、空きが多ければ最適化します。
- 同じタイミングで、定期バックアップを作ります。「ファイル → 今すぐバックアップ」で手動でも作れます。

## 更新

起動中は 1 日に 1 回、新しい版を確かめます。手動で確かめるには「ヘルプ → Yorimichi について…」の「更新を確認」を押します。更新は、インストーラーで入れた版でだけ動きます。
